Meal Plan Generator

Algorithm Explanation

The program uses a loop to go through the food database. It randomly changes the order of the foods. It then checks whether each food fits into the remaining calories. If the food fits, it is added to the meal plan. If it does not fit, the program skips it. This makes sure the meal plan never goes over the target calories.
